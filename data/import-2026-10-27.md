# Premier import — 27 octobre 2026

Le catalogue contient **423 fiches** établies à partir de l’export fourni par le propriétaire du site. Certaines fiches décrivent une campagne collective de recrutement ; ce nombre ne représente donc pas un décompte de postes individuels.

Les 647 messages de l’export ont tous été classés :

| Traitement                                                            | Messages |
| --------------------------------------------------------------------- | -------: |
| Annonces de recrutement retenues comme sources principales            |      363 |
| Relances, copies ou annonces recouvrant un recrutement déjà référencé |       53 |
| Messages hors recrutement                                             |      231 |
| Total examiné                                                         |      647 |

Les messages hors recrutement comprennent notamment des appels à contributions, conférences, ateliers, alertes bibliographiques, enquêtes, formations, candidatures spontanées et correspondances personnelles. Les annonces comportant plusieurs postes distincts ont été séparées lorsque leurs profils ou catégories le justifiaient. Les campagnes de postes de même catégorie peuvent rester collectives. Les campagnes générales et leurs annonces spécialisées peuvent se recouper ; ne pas utiliser le nombre de fiches comme mesure du nombre de postes.

Les courriels et pièces jointes ont servi uniquement de références privées. Les données publiées se limitent aux intitulés, métadonnées de recrutement, résumés factuels rédigés, contacts de recrutement explicitement proposés et références minimales. Aucun message original, en-tête, signature, destinataire privé, lien de désabonnement, nom de fichier d’export ou pièce jointe n’est ajouté au dépôt.

Les informations manquantes restent `null`. Les échéances de priorité ou d’examen ne sont pas traitées comme des clôtures. Les dates contradictoires sont signalées dans les résumés. Les offres anciennes restent disponibles avec une indication d’échéance passée. Cet import ne constitue pas une vérification auprès des employeurs de la disponibilité actuelle de chaque poste.

Les anciens exemples fictifs, la réception de courriels, les traitements par file d’attente, les tâches planifiées, les intégrations d’extraction et les migrations de base distante sont retirés de l’application. Le site utilise uniquement `opportunities.json` et des fichiers statiques.
